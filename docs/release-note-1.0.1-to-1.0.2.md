# Release Note: v1.0.1 → v1.0.2

## 릴리즈 일자
2026-07-07

## 변경 사항

### 신규 기능
- 태스크 바 리사이즈 기능 (왼쪽/오른쪽 경계 드래그로 시작일/종료일 조절)
- 리사이즈 중 반투명 프리뷰 바 + 날짜 툴팁 표시
- 팀 내 태스크 상하 이동 (0.5행 단위 드래그)
- 전체화면 보기에서 이미지 다운로드 (html2canvas 고해상도 3x)
- 이미지에 프로젝트 제목 + 팀명 + 신호등 전체 포함
- 데이터 내보내기(.dat) / 가져오기 기능 (브라우저 간 데이터 이동)
- 팀 관리 기능 (공통 팀 + 프로젝트별 팀)
- 팀 순서 드래그&드롭 (태스크 관리 + 간트 차트 동기화)
- 프로젝트별 신호등/각주/팀순서 독립 관리
- Electron 기반 Windows exe 설치 파일 생성
- GitHub 리포지토리 공개

### 디자인 변경
- 태스크 바 그림자 효과 추가
- 태스크명 말줄임표 처리 (기간 표시와 겹침 방지)
- 하단 시간축 추가 (상단과 동일한 월/일 + 오늘/출시일 라벨)
- 오늘 기준선을 가장 앞으로 (태스크 바 위에 표시)
- 신호등 위치를 팀 오른쪽으로 이동 + 글로우 그림자
- 팀 라벨 너비 동적 조절 (가장 긴 팀명 기준)
- 타이틀 "[프로젝트명] (날짜 기준)" 형식으로 변경

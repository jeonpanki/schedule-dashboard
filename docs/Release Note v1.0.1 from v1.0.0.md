2026-07-07

## 변경 사항

### 신규 기능
- 팀별 신호등 기능 추가 (안심/주의/위험 3단계)
- 각주 추가/편집/삭제 기능
- 태스크 바 드래그&드롭으로 일정 이동 (선행 태스크 이동 시 후행 태스크 연동)
- 드래그 중 날짜 툴팁 표시
- 태스크 관리에서 팀별 아코디언 그룹 (펼치기/접기)
- 태스크 수정 기능 (인라인 편집)
- 팀 드롭다운으로 담당팀 선택 (기본 팀 목록 제공)
- 선행/후행 태스크 2단계 드롭다운 (팀 → 태스크)
- 간트 차트에서 태스크 라벨 더블클릭 인라인 편집
- 전체화면으로 보기 기능

### 디자인 변경
- 태스크 바: 흰색 배경 + 검정 테두리 + 둥근 모서리(rx=4)
- 이벤트: 녹색 원형 DOT + [M/D] 날짜 라벨
- 출시일: 빨간 별(★) 마커
- 오늘 날짜: 녹색 점선 + "오늘" 라벨
- 팀별 경계 가로 구분선
- 바 안에 태스크명(왼쪽) + 기간(오른쪽) 표시

### 버그 수정
- 이벤트 태스크 날짜가 역산으로 변경되던 버그 수정
- 태스크 수정 시 간트 차트에 반영되지 않던 버그 수정
- 타임존 문제로 날짜가 하루 밀리던 버그 수정

### 기타
- PPT 내보내기 디자인 개선 (pkindex.html 스타일 적용)
- 간트 차트 출시일+5일까지 한 화면에 표시
- "간트 차트" → "일정 마일스톤" 문구 변경
